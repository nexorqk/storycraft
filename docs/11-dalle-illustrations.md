# DALL-E 3 Illustration Generation

Date: 2026-05-15

## Scope

This slice adds AI-powered illustration generation using DALL-E 3, creating
images for each book page based on the illustration prompts generated by the
story text provider.

## Backend

### IllustrationProvider Interface

Located in `apps/api/src/generation/illustration-types.ts`.

```ts
interface IllustrationProvider {
  generate(request: IllustrationRequest): Promise<IllustrationResult>;
}
```

- `IllustrationRequest`: prompt, bookId, pageNumber.
- `IllustrationResult`: image buffer (PNG) and MIME type.

### DallEProvider

Located in `apps/api/src/generation/dalle.provider.ts`.

- Uses the same OpenAI SDK client as the text provider.
- Model: `dall-e-3` (configurable via `DALLE_MODEL`).
- Size: `1024x1024` (configurable via `DALLE_SIZE`).
- Quality: `standard` (configurable via `DALLE_QUALITY`).
- Returns `b64_json` which is decoded to a PNG buffer.

### GenerationService Integration

Updated `generateBook()` flow:

1. Generate story text for each page (OpenAI gpt-4o-mini).
2. Create `BookPage` record with text and illustration prompt.
3. Generate illustration using `DallEProvider.generate()` with the page's
   illustration prompt.
4. Upload illustration to S3/Garage at `illustrations/{bookId}/{pageNumber}.png`.
5. Create `Illustration` record with:
   - `pageId` linking to the `BookPage`;
   - `status: 'COMPLETED'`;
   - `objectKey` for the S3 object;
   - `provider: 'dall-e'`.

### Environment Variables

| Variable | Default | Description |
|---|---|---|
| `DALLE_MODEL` | `dall-e-3` | DALL-E model to use |
| `DALLE_SIZE` | `1024x1024` | Image size (`1024x1024`, `1024x1792`, `1792x1024`) |
| `DALLE_QUALITY` | `standard` | Image quality (`standard`, `hd`) |

### Storage Integration

Illustrations are uploaded to S3/Garage using `StorageService`:

- Object key pattern: `illustrations/{bookId}/{pageNumber}.png`
- MIME type: `image/png`
- The `Illustration.objectKey` stores the S3 path for download.

### Module Dependencies

`GenerationModule` now imports `StorageModule` and provides `DallEProvider`.

## Design Decisions

- **Provider abstraction**: `IllustrationProvider` interface allows swapping
  image generation providers (e.g., Stable Diffusion, Midjourney API).
- **Sequential generation**: Illustrations are generated one at a time after
  text is ready, ensuring the prompt matches the generated story.
- **S3 storage**: Images are stored in object storage, not in the database.
  Only the object key is persisted.
- **Same API key**: DALL-E 3 uses the same `OPENAI_API_KEY` as gpt-4o-mini.
