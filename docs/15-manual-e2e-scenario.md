# Ручной E2E-сценарий тестирования Storycraft

## Предусловия

- Сайт доступен по `https://storycraftbooks.com`.
- У тестировщика есть рабочий Google-аккаунт (можно тестовый).
- В `.env` включена реальная генерация (`USE_MOCK_AI=false`) или для дыма можно оставить `true`, но тогда пункты про AI будут проходить мгновенно.
- Браузер: Chrome/Firefox/Safari последней стабильной версии.

---

## Сценарий 1. Авторизация и первый вход

**Цель:** Проверить Google OAuth, редиректы и базовую навигацию.

| Шаг | Действие                                               | Ожидаемый результат                                                        |
| --- | ------------------------------------------------------ | -------------------------------------------------------------------------- |
| 1.1 | Открыть `https://storycraftbooks.com` в приватном окне | Открывается страница логина с кнопкой «Continue with Google»               |
| 1.2 | Нажать «Continue with Google»                          | Редирект на `accounts.google.com`, выбор аккаунта                          |
| 1.3 | Выбрать аккаунт и пройти OAuth                         | Редирект обратно на `/auth/callback`, затем на `/`                         |
| 1.4 | Проверить Dashboard                                    | Виден блок приветствия, имя пользователя в AuthPanel, боковое меню активно |

---

## Сценарий 2. Управление профилем ребёнка

**Цель:** CRUD профилей детей.

| Шаг | Действие                                                              | Ожидаемый результат                                 |
| --- | --------------------------------------------------------------------- | --------------------------------------------------- |
| 2.1 | Перейти в **Children** через боковое меню                             | Открывается форма добавления и пустой список        |
| 2.2 | Заполнить имя, дату рождения, интересы (например, «космос, животные») | Поля заполнены                                      |
| 2.3 | Нажать «Add Child»                                                    | В списке появляется карточка ребёнка с тегами       |
| 2.4 | Нажать «Edit» на карточке                                             | Открывается форма редактирования с текущими данными |
| 2.5 | Изменить интересы, сохранить                                          | Карточка обновилась, изменения сохранены            |
| 2.6 | Нажать «Delete» на карточке, подтвердить                              | Карточка исчезла из списка                          |

---

## Сценарий 3. Создание и генерация книги (happy path)

**Цель:** Полный цикл от выбора до готовой книги.

| Шаг | Действие                                                   | Ожидаемый результат                                                                |
| --- | ---------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| 3.1 | Перейти в **Create**                                       | Виден список детей и шаблонов                                                      |
| 3.2 | Выбрать ранее созданного ребёнка                           | Карточка ребёнка подсвечена/отмечена                                               |
| 3.3 | Выбрать шаблон (например, «Приключение в космосе»)         | Карточка шаблона подсвечена, видна панель деталей шаблона                          |
| 3.4 | Нажать «Review & Create»                                   | Открывается экран подтверждения с выбранным ребёнком и шаблоном                    |
| 3.5 | Нажать «Create Book»                                       | Создаётся книга, редирект на `/books`, статус книги **PENDING** или **GENERATING** |
| 3.6 | Открыть созданную книгу                                    | Виден прогресс-бар, статус «Generating…»                                           |
| 3.7 | Подождать 2–5 минуты (с реальным AI) или обновить страницу | Статус меняется на **COMPLETED**, появляется кнопка «Download Book»                |
| 3.8 | Нажать «Download Book»                                     | Начинается скачивание файла или открывается presigned URL                          |

---

## Сценарий 4. Просмотр библиотеки и статусов

**Цель:** Проверить список книг, статусы и фильтрацию.

| Шаг | Действие                                  | Ожидаемый результат                                                                  |
| --- | ----------------------------------------- | ------------------------------------------------------------------------------------ |
| 4.1 | Перейти в **Books**                       | Виден список книг с датами, статусами и детьми                                       |
| 4.2 | Проверить цвета/иконки статусов           | PENDING — серый, GENERATING — жёлтый/синий, COMPLETED — зелёный, FAILED — красный    |
| 4.3 | Нажать на книгу со статусом **COMPLETED** | Открывается детальная страница с иллюстрациями, текстом страниц и кнопкой скачивания |
| 4.4 | Проверить иллюстрации                     | Изображения загружаются, нет битых ссылок                                            |

---

## Сценарий 5. Управление аккаунтом

**Цель:** Экспорт данных и удаление аккаунта.

| Шаг | Действие                                  | Ожидаемый результат                                                         |
| --- | ----------------------------------------- | --------------------------------------------------------------------------- |
| 5.1 | Перейти в **Settings**                    | Видны кнопки «Export Data» и «Delete Account»                               |
| 5.2 | Нажать «Export Data»                      | Через несколько секунд начинается скачивание `.json` с данными пользователя |
| 5.3 | Открыть скачанный JSON                    | Внутри есть массив `books`, `children`, `user` — структура корректная       |
| 5.4 | Нажать «Delete Account», подтвердить      | Происходит редирект на `/login`, сессия аннулирована                        |
| 5.5 | Попытаться зайти снова через Google OAuth | Создаётся **новый** пользователь (старый данных не имеет)                   |

## Сценарий 6. Тёмная тема

**Цель:** Проверить переключатель тем и сохранение выбора.

| Шаг | Действие                                              | Ожидаемый результат                                                             |
| --- | ----------------------------------------------------- | ------------------------------------------------------------------------------- |
| 6.1 | В боковом меню нажать выпадающий список **Theme**     | Есть 3 опции: System, Light, Dark                                               |
| 6.2 | Выбрать **Dark**                                      | Интерфейс мгновенно переключается на тёмную палитру (тёмный фон, светлый текст) |
| 6.3 | Перезагрузить страницу                                | Тема остаётся тёмной (сохранена в `localStorage`)                               |
| 6.4 | Выбрать **System**                                    | Тема следует за настройками ОС (проверить: включить/выключить тёмную тему в ОС) |
| 6.5 | В приватном окне (чистый `localStorage`) открыть сайт | При первом визите тема определяется по `prefers-color-scheme`                   |

## Сценарий 7. Безопасность и доступность

| Шаг | Действие                                                       | Ожидаемый результат                                                        |
| --- | -------------------------------------------------------------- | -------------------------------------------------------------------------- |
| 7.1 | Открыть `/books` без авторизации (новая вкладка, не залогинен) | Редирект на `/login` или 401                                               |
| 7.2 | Открыть `/api/books` напрямую                                  | Возвращает `401 Unauthorized`                                              |
| 7.3 | Проверить cookie сессии                                        | `storycraft_session` — `httpOnly`, `secure` (в production), `sameSite=lax` |
| 7.4 | Проверить работу на мобильном разрешении (DevTools 375×667)    | Боковое меню скрыто/адаптировано, контент читаем, кнопки кликабельны       |
